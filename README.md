# Sweet-Crumbs-Bakery
For Part 2, I improved my Sweet Crumbs Bakery website by adding CSS and making the website more responsive.

Changes I Made
I created an external style.css file and linked it to all my HTML webpages.
I added CSS styling for the background colours, text, headings, tables, buttons, forms and images.
I kept the original bakery colour theme from Part 1.
I added hover effects to the navigation links and buttons.
I used Flexbox for the feature sections and gallery.
I added responsive design using media queries so that the website can adjust to different screen sizes.
I made the images responsive so they can resize on smaller screens.
I added styling to the order and login forms.
I added focus styling to form fields when they are selected.
I tested the webpages on a smaller screen to make sure the pages, navigation, images and forms still work correctly.
I kept the original content, pages and bakery information from Part 1 while improving the appearance and responsiveness for Part 2.
